The social media blocker is a desktop application which helps people stay away from social media during their work or productivity. It is built on Visual Studio by using C sharp . .Net framework has been used . Multiple forms run in the desktop application. When user click on any social media a new form loads up where a timer is present. The user has to a timer before accessing the app. It can 1 seconds to 24 hours. Once a user sets timer the app will not be able accessible until the timer ends. Hence, this will help the user to break his distraction and regain his attention span.
